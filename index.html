My approach

How I apply AI

The model is the easy part. Making it useful to a real team means designing for trust, cost and the moment a human needs to step in

01

Start from the chore, not the model

I pick work people repeat every week and already find tedious, then automate that exact loop

02

Verify before anyone sees it

Agents check their own findings against the source of truth, and a human approves before anything is posted or merged

03

Measure the cost

Token counts, caching and hard budgets from day one, so a useful tool stays cheap enough to keep running

2026 · Multi-agent

PR review fleet

Reviews the whole team's open PR queue in one go: one subagent per pull request, each finding checked against the code before it's reported

  • Fan out: one reviewer agent per open PR, covering correctness, security, tests and UX
  • Verify: every finding is proved against the code at HEAD, so false positives never reach the author
  • Reconcile: a final pass checks no PR was silently dropped
  • Approve: I see one summary table, ranked by which PRs need human eyes, and nothing posts until I sign off

Keeps review turnaround fast for the squad while I stay on feature work, and teammates get short, inline, verified comments
